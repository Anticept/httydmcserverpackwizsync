# HTTYD Minecraft Server Modpack

This has been packwizified to make it easy to sync mods. The big modpack is the Dawn of Berk modpack, but numerous other things have been added.

This isn't a modpack for distribution other than to make it easy to sync for joining the HTTYD MC Server. That's it.

But just in case: copyrights held by their respective owners. See each pw.toml file and the dawn of berk modpack for sources to retrieve licenses.
